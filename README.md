# meshlink

Mesh identifiers and link tokens for idempotent workflows.

**Site:** https://theworker02.github.io/meshlink/

## Install / run

```bash
git clone https://github.com/theworker02/meshlink.git
cd meshlink
node src/cli.js
node --test
```
